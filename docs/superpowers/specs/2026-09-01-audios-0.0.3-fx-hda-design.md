# audiOS 0.0.3 — ASRock 960GM-GS3 FX

v0.0.3 makes analog playback work on the machine this OS is actually for: an AM3+ ASRock 960GM-GS3 FX (AMD 760G + SB710, Realtek ALC662, green rear line-out).

## Approach

The SB710 exposes an HDA controller at PCI `1002:4383` (class 04:03). The kernel maps BAR0 into the HHDM as uncacheable pages (Limine base revision 3+ does not map PCI BARs), resets GCTL, and walks the codec with immediate commands (ICS at 0x60/0x64/0x68 — enough for setup verbs; CORB/RIRB is optional):

- Prefer ALC662 pin **0x14** (the green “Front Speaker” jack on this board)
- Otherwise pick a connected line-out / HP / speaker pin
- Follow the connection list through mixers to a DAC
- Unmute amps **only on widgets that advertise one**, set D0, enable pin OUT (and EAPD when the pin advertises it)
- DMA 48 kHz 16-bit stereo; the engine still runs at 96 kHz logical and resamples

QEMU’s `ich9-intel-hda` + `hda-output` is walked the same way so `make test` proves a 440 Hz capture without the FX box. Intel ICH AC97 stays as a fallback backend.

## Out of scope

USB HID, USB audio, HDMI, 5.1 extra jacks, disk install, networking.

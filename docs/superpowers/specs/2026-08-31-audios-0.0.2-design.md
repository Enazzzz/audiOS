# audiOS 0.0.2 Design

v0.0.2 turns the 0.1 shell into a minimal audio computer: detect a device, configure it, generate test signals, play PCM WAV, and keep the OS alive when audio fails.

## Approach

PCI enumeration finds multimedia-class functions. Intel ICH AC97 is the first playback backend (QEMU `-device AC97` and similar ICH parts). The engine renders stereo s16 into a 32-period DMA ring of `buffer` frames (default 64) and is pumped from the shell idle loop so playback is continuous without blocking the CLI.

Logical configuration stays 44.1 / 48 / 96 kHz, 16- or 24-bit, 1–2 channels. AC97 hardware is 16-bit stereo at its native rate (usually 48 kHz); the engine resamples with 16.16 fixed-point so a 96 kHz session still produces a 440 Hz tone on a 48 kHz DAC.

WAV files ship on the ISO as Limine modules (`test.wav`, plus deliberately invalid files). `play` looks them up by basename. Unsupported formats return an error string; they do not halt the kernel.

## Commands

`audio` `audio devices` `audio info` `audio set` `audio status` `audio test`
`tone <sine|square|saw|noise|silence> [freq] [amp] [duration]`
`play <file.wav>` `stop`

## Verification

`make test` boots QEMU with AC97 and a WAV audiodev, drives the command set over serial, then checks the capture for a dominant 440 Hz tone.

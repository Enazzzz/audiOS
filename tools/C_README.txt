audiOS C:  (system volume)

All files here are temporary until the next update.

A C: update (Windows: update-system.ps1, Linux: update_system.py,
or writing partition 1) replaces this entire volume: kernel, boot
files, and anything you saved on C:.

Keep files you care about on D:.
C:/boot/floppy.img is the 1.44 MB Limine disk (`floppy install` writes it to A:).
/os is another name for C:.
E: is a second USB stick if one is plugged in.
